## Resume

Cette MEP corrige deux points de production importants.
Le parcours utilisateur conserve maintenant la langue courante sur les pages compte, login et profil afin d'eviter de repasser automatiquement vers une autre langue.
La production ne repose plus sur `vite preview` : l'application est configuree pour etre servie avec le serveur Node officiel de SvelteKit via `@sveltejs/adapter-node`.
Cette base est plus adaptee au VPS, au reverse proxy Nginx et au domaine `ethiohub.online`.

## Changements inclus

- Routing langue
  - Ajout de `login` et `profile` dans les routes statiques localisees.
  - Le bouton compte de l'en-tete pointe maintenant vers `/{lang}/login` ou `/{lang}/profile`.
  - Les redirections login/profil utilisent la langue courante comme contexte.
  - Ajout des routes localisees `/fr/login`, `/en/login`, `/am/login`.
  - Ajout des routes localisees `/fr/profile`, `/en/profile`, `/am/profile`.
  - Ajout de tests i18n pour les chemins `login` et `profile`.

- Authentification et profil
  - Le flow email + OTP conserve le chemin de retour dans la langue courante.
  - Le profil redirige les utilisateurs non authentifies vers le login localise correspondant.
  - Le lien profil apres connexion reste dans la langue active du site.

- Production VPS
  - Remplacement de `@sveltejs/adapter-auto` par `@sveltejs/adapter-node`.
  - Ajout du script `start` pour lancer le serveur produit avec `node build`.
  - Mise a jour du lockfile avec `@sveltejs/adapter-node`.
  - Preparation d'un deploiement compatible avec un service systemd et un reverse proxy Nginx.

## Impact technique

- VPS / systemd
  - Le service `ethio-videos` doit etre mis a jour pour lancer `node build` au lieu de `pnpm preview`.
  - Variables recommandees dans le service systemd :
    - `NODE_ENV=production`
    - `HOST=127.0.0.1`
    - `PORT=3000`
    - `ORIGIN=https://ethiohub.online`
  - Exemple d'`ExecStart` attendu : `/usr/bin/node build`.

- Nginx
  - Nginx doit continuer a proxyfier vers `http://127.0.0.1:3000`.
  - Le header `Host` peut rester sur `$host`, car le serveur Node SvelteKit ne depend plus du host-check de Vite preview.
  - Le domaine `ethiohub.online` et `www.ethiohub.online` doivent etre declares dans `server_name`.

- Deploiement
  - Le workflow de deploiement continue de lancer `pnpm install --frozen-lockfile`, `pnpm prisma generate`, `pnpm prisma migrate deploy` et `pnpm build`.
  - Apres cette MEP, le build genere une sortie Node dans `build/`.
  - Le redemarrage systemd doit utiliser le nouveau service avant validation finale en production.

- Base de donnees
  - Aucune migration Prisma ajoutee par cette MEP.

- Risques connus
  - Si le service systemd reste configure sur `pnpm preview`, l'erreur Vite `Blocked request. This host is not allowed` peut continuer.
  - Verifier apres deploiement que `http://ethiohub.online` puis `https://ethiohub.online` repondent correctement via Nginx.
  - Verifier les pages `/fr/login`, `/en/login`, `/am/login`, `/fr/profile`, `/en/profile`, `/am/profile`.
